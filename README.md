# heywaja-releases

HeyWaja macOS release artifacts only — **no source code**.

- Each release (`vX.Y.Z`) holds the notarized DMG (`HeyWaja-X.Y.Z.dmg`) and a static `appcast-<channel>.xml` cold-standby snapshot.
- Update metadata feed is served live at https://heywaja.com/api/appcast?channel=beta|stable
- Download: https://github.com/amanurat/heywaja-releases/releases/latest
